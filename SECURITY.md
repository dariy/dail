# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository.
Do not open a public issue for them.

These reports matter most:
- email content (bodies, subjects, names, attachments) that gains authority over the app or a connected agent;
- an agent (MCP) reaching a user-only command, or sending mail without the user's approval;
- credentials leaving the OS keyring, or reaching logs, receipts, replay logs or a server they were not meant for;
- TLS validation issues in `app-tls`.

Only the latest commit on `main` is supported. You will get an answer within two weeks.
